ABOUT THE PROJECT

Technology with a human purpose.

AI SmartCane Assist — An AI-Powered Smart Navigation System for the Visually Impaired is a software project concept focused on accessible mobility.

The project report proposes a React Native mobile application, an on-device TensorFlow Lite object-detection model, Google Maps-based outdoor navigation, spoken feedback, vibration alerts, caregiver management, and emergency SOS support.
