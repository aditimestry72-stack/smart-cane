AI SmartCane Assist — Website Prototype

FILES
- index.html: page structure and content
- style.css: responsive layout and styling
- script.js: mobile navigation, spoken sample cue, Google Maps search, and SOS preview

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a modern browser (Chrome, Edge, Firefox, or Safari).
3. For best results, keep the three files in the same folder and stay connected to the internet for Google Fonts and the Google Maps link.

IMPORTANT PROJECT LIMITATIONS
This is a front-end website prototype based on the supplied project report. It is not the full mobile app. It does not include a trained TensorFlow Lite model, live camera object detection, GPS turn-by-turn navigation, a backend database, or real SOS messaging. The route control opens a Google Maps search; the SOS button only shows a sample message. Real safety functionality requires a separately developed and tested mobile app, model, permissions, and messaging integration.

TECHNOLOGIES
HTML5, CSS3, JavaScript, browser SpeechSynthesis API, Google Maps search URL.
